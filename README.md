# Чтение текста интерфейса

Вторая часть зрения рабочего агента: модель читает надписи на кнопках,
в меню, списках и полях. Без этого агент не отличит **Save** от **Load** и
будет кликать наугад.

Работает в шести программах: **UE5, UE4, Blender, Blockbench, браузер
(Chrome/Яндекс), проводник Windows 11**.

## Зачем отдельная модель

Общая модель зрения (репозиторий `AI-Learning`) находит элементы на экране
и выдаёт их координаты. Она смотрит на кадр целиком и по своей природе не
может читать: при входе 1280×720 полносвязный слой разросся бы до 51 млн
параметров и уничтожил бы пространственную структуру.

Здесь другая архитектура — **CRNN + CTC**: свёртки сжимают вырез строки по
высоте до одной клетки, оставляя ширину, двунаправленная GRU читает
получившуюся ленту колонок. Всего **1.4 млн параметров** — модель
вызывается на каждый найденный элемент, поэтому обязана быть лёгкой.

## Важное ограничение по разрешению

Надпись интерфейса — примерно 12 пикселей в высоту на экране 1672×941.
При сжатии кадра она становится нечитаемой:

| вход модели | высота текста | читается |
|---|---|---|
| 640×360 | 4.6 px | **нет** |
| 960×540 | 6.9 px | на пределе |
| **1280×720** | **9.2 px** | **да** |
| 1920×1080 | 13.8 px | да |

Поэтому общее зрение работает на 1280×720, а вырезы строк подаются сюда в
исходном масштабе, приведённые к высоте 32 пикселя.

## Данные

Строки рисуются настоящими шрифтами (**Roboto** — тот же, что в
`Engine/Content/Slate/Fonts`) поверх подлинных цветов панелей: тёмные темы
редакторов, светлые темы проводника и браузера. Текст берётся из словаря
реальных подписей — 254 надписи из шести программ, плюс генерируемые имена
ассетов, числа и имена файлов.

## Запуск

```bash
pip install -r requirements.txt
python3 train_text.py --samples 60000 --epochs 30
python3 -m pytest tests/ -q       # 12 passed
```

## Что уже получено

Пробный прогон (4 000 строк, 14 эпох, 2 ядра) — модель научилась читать:

```
верно   ожидалось 'SM_B'          прочитано 'SM_B'
верно   ожидалось 'BP_Inst'       прочитано 'BP_Inst'
верно   ожидалось 'file69.png'    прочитано 'file69.png'
ОШИБКА  ожидалось 'New Tab'       прочитано 'New Tas'
```

| метрика | 14 эпох на 4 000 строк |
|---|---|
| строка прочитана точно | 43.0 % |
| символы угаданы | 65.9 % |
| подпись узнана целиком | 71.6 % |

Кривая на момент остановки круто росла — это разминка, а не потолок.
Полный прогон идёт на 60 000 строк и 30 эпох.

## Две головы

1. **Посимвольное чтение (CTC)** — читает что угодно: имена файлов,
   числа в полях свойств, незнакомые названия.
2. **Узнавание подписи целиком** — для 254 известных пунктов меню это
   надёжнее чтения по буквам и сразу даёт агенту готовый ответ.
